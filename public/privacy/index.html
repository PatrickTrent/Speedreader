What happens when you read

You paste text, or you pick a PDF or DOCX on your computer. The file is read in the browser. This project has no upload URL and no serverless function that receives the document for ordinary RSVP reading.

  • → A PDF is turned into text in the page with PDF.js 3.4.120 (the script is loaded from cdnjs.cloudflare.com). The code hands the file’s bytes, already in memory, to getDocument. It does not post the PDF to us.
  • → A DOCX is turned into text in the page with Mammoth 1.6.0 (also loaded from cdnjs), again from those in-memory bytes.
  • → Pasted text is stored only in the page.

Play, pause, the words-per-minute slider, and full screen then show that text one word at a time. Those controls do not send the document anywhere. The code does not set a PDF.js worker address or a character-map address. Until you upload or paste, the player shows a demo sentence that is written into the app, not a file of yours.

The file name and the extracted text stay in the page’s memory for the visit. This code does not write them to localStorage. Closing or reloading the tab drops them. Errors from a failed file read are printed to the browser console only. They are not sent to a logging service by this code.

What happens with the AI summary

AI summary is optional. RSVP reading does not use it and does not send your text to Google. One summary that returns a response spends one credit on this device. A failed request does not.

What goes to Google Gemini is the extracted text, truncated. The summary sends only the first 35,000 characters of that text (rawText.substring(0, 35000)). If the text is shorter, the whole extracted text is included. If it is longer, everything after character 35,000 is left out. The original PDF or DOCX file is not attached. With that slice, the request also sends a short instruction (summarize for a speed reader, at most 600 words) and a system instruction (executive-summary style, in capitals). Those instructions are not part of the 35,000-character cut.

The browser calls Google’s Gemini API itself. The code uses the @google/genai library as new GoogleGenAI({ apiKey }), model gemini-3-flash-preview. It does not set a Vertex project, a region, or a custom API address, and there is no serverless function in this repository in front of the call. The key is GEMINI_API_KEY, inserted when the app is built, so the request leaves your browser. Google sees your IP address together with that truncated text.

The locked @google/genai release in this project (1.52.0) sends that API-key call to https://generativelanguage.googleapis.com/ on API version v1beta.

The reply is shown in the reader on this page. This code does not write it to a database. “At most 600 words” is only an instruction to the model. The code does not trim the reply to 600 words.

Credits, still with no account

The balance is a number in localStorage on this browser, under the key creditBalance. If nothing is saved yet, the app starts at 2 credits. There is no login, so the balance does not follow you to another browser or phone. Clearing site data for this site deletes it. Nothing in this repository looks up a Stripe payment and puts the credits back.

When the page loads with success=true and a credits number in the address, it adds that number to the local balance and then removes those parameters from the address. This repository does not check that number against Stripe.

Payments via Stripe

The buy buttons send the browser to a Stripe Payment Link. Starter is 5 credits for €0,99. Pro is 50 credits for €3,99. The app does not add your document, your name, or your email to that link. You type card details on Stripe’s page. This app never reads the card number.

A Stripe publishable key sits in the app source, and the homepage loads Stripe.js from js.stripe.com. The checkout path in this code is still only the redirect to the Payment Link. The publishable key is not used to open a card form here.

The repository also contains server.py, a small Flask app. Its POST /webhook route checks a Stripe signature and, for checkout.session.completed, prints the Checkout session id. It does not save the event in a database, and it does not receive your document. The web app does not call this route.

What this browser stores, and other requests

The credit balance is stored in this browser under the localStorage key creditBalance.

Opening the homepage loads scripts and fonts from these hosts, so they see your IP address and ordinary browser headers. This code does not send them your document:

  • → cdn.tailwindcss.com
  • → js.stripe.com
  • → cdnjs.cloudflare.com (PDF.js and Mammoth)
  • → fonts.googleapis.com (Inter and JetBrains Mono)

Your extracted text is sent off this page only if you run AI summary. Then Google Gemini receives the first 35,000 characters of that text, plus the short instructions above. The rest is not sent.

Copyright and confidential text

Do not put copyrighted material you are not allowed to share, or confidential material (passwords, customer data, private documents), into the AI summary. That path sends the first 35,000 characters of the extracted text to Google. RSVP reading alone does not send that text to a Speedreader server or to Gemini. The script and font requests above still happen when you open the site.
